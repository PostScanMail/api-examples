# Python Examples

## Requirements
- Python 3.9+
- requests

Install:
```bash
pip install -r requirements.txt
```

## Setup
```bash
export PSM_BASE_URL="https://api.postscanmail.com/api/account-docs/v2"
export PSM_API_KEY="YOUR_API_KEY"
```

For item actions:
```bash
export ADDRESS_ID="ADDRESS_ID"
export MAIL_IDS="MAIL_ID_1,MAIL_ID_2"
```
